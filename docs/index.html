Three tabs. Everything you'd want to know.

Tokens reads the logs your agents already write. It's ready the moment it launches and updates about a second after an agent writes.

Overview

Tokens and API-equivalent cost for today, 7 days, 30 days or all time. Hourly, daily and weekly charts, a per-agent breakdown, top models and insights.

Months

Monthly totals, a 20-week activity heatmap, and each month's value compared with what your plans cost.

Plans

Your subscriptions' value multiple, the day each one breaks even, effective cost per 1M tokens, and live Codex 5-hour and weekly limit gauges.

Your usage never leaves your Mac

Tokens only keeps token counts, model names and timestamps. It never stores prompt or response text, and it has no network code at all.

0

network requests, accounts, trackers and dependencies

~1 s

from an agent writing a log line to the menu bar updating, via FSEvents

Δ only

Logs are append-only, so after the first scan only new bytes are parsed

Install

Build from source in about a minute. Requires macOS 26+ and Xcode 26+.

git clone https://github.com/Felix-Bergmann-Code/tokens.git
cd tokens
./scripts/build.sh --install   # builds, copies to ~/Applications and launches

Prices change. Agents multiply.

Pull requests are very welcome. Updating a model price in Pricing.swift takes five minutes and helps everyone. Support for Gemini CLI, Cursor, Aider or OpenCode would be even better.
